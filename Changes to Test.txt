Test Scenarios
Queuing Test
For each operation above:
Perform the action (create/update/delete)
Verify it's added to sync_operations table
Verify sync_status is set to 'pending'
Verify sync debug log shows: MADE → QUEUED
Verify queue entry has correct operation_type, table_name, record_id, data
Sync-to-Server Test
For each queued operation:
Get pending operations from sync_operations table
Attempt to sync each operation
Verify operation succeeds on server
Verify server_id is set in local database
Verify sync_status changes to 'synced'
Verify operation is removed from queue (or marked completed)
Verify sync debug log shows: QUEUED → SYNCED_TO_SERVER
Sync-from-Server Test
After syncing on Device 1:
Login on Device 2 (new device)
Verify all doctors from server download to local
Verify all meetings from server download to local
Verify all follow-ups from server download to local
Verify all notes from server download to local
Verify all saved brochures from server download to local
Verify brochure modifications (groups, renamed slides, etc.) download
Verify sync debug log shows: SYNCED_FROM_SERVER for each record
Compare counts: Local = Server = Synced logs

Verification Points
For each change, verify:
Queuing: Is it in the sync queue?
Sync Status: Is sync_status = 'pending'?
Debug Logs: Does log show MADE → QUEUED?
Server Sync: Does it sync successfully?
Server ID: Is server_id set after sync?
Download: Does it download on new device?
Data Integrity: Is data correct on new device?
